# INSTANT — Arena Duel

A self-contained 3D first-person duel: you vs one AI rival in a covered arena.

## Run locally

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765`.

## Controls

- **↑ / ↓** — move forward / back
- **← / →** — turn
- **Space** — shoot
- **W A S D** — optional (move + strafe)

## Stack

Static HTML/CSS/JS with Three.js (CDN import map). No build step.
